## ฟังก์ชันการทำงานหลัก
1. **หน้าแรก (Home):**
   - Hero Banner ภาพสไลด์เปลี่ยนอัตโนมัติทุก ๑๐ วินาที (หรือแสดงภาพนิ่งหากมีรูปเดียว)
   - นาฬิกานับถอยหลังสู่กำหนดการสอบและกิจกรรม (Countdown Timer)
   - บัตรนำทาง ๓ รายการ (แบบทดสอบออนไลน์, ตรวจสอบคะแนน, เกียรติบัตร)
   - ข้อมูลโครงการวิชาการและมรดกสุนทรภู่
   - เกณฑ์การได้รับเกียรติบัตร (เหรียญทอง, เหรียญเงิน, เหรียญทองแดง, รางวัลชมเชย) — การ์ดจัดกึ่งกลางอัตโนมัติเมื่อจำนวนเปลี่ยน
   - กำหนดการสำคัญและไทม์ไลน์กิจกรรม
   - ประกาศและข่าวสารจากคณะกรรมการ
2. **ระบบทำแบบทดสอบออนไลน์ (Examination):**
   - แยกข้อสอบ ม.ต้น (ม.๑–๓) และ ม.ปลาย (ม.๔–๖)
   - เชื่อมต่อไปยัง Google Forms ทางการ พร้อมคำชี้แจง เวลาสอบ และจำนวนข้อ
3. **ระบบตรวจสอบคะแนนสอบ (Score Checking):**
   - อ่านข้อมูลจากแผ่นงาน `'ตรวจสอบคะแนน'!A:F`
   - ค้นหาด้วยชื่อ-นามสกุล พร้อมระบบตัดคำนำหน้าภาษาไทยอัตโนมัติ
   - แสดงเลขที่, ชื่อ-นามสกุล, ระดับชั้น, ห้อง, คะแนนที่ได้ (คอลัมน์ E) และผลการประเมิน (คอลัมน์ F)
   - ป้ายกำกับผลการประเมิน ผ่าน (สีเขียว) / ไม่ผ่าน (สีแดง)
   - ป้องกันการเข้าถึงข้อมูลวงกว้างกรณีมีชื่อซ้ำ
4. **ระบบเกียรติบัตรอิเล็กทรอนิกส์ (Certificate Download):**
   - อ่านข้อมูลจากแผ่นงาน `'ดาวน์โหลดเกียรติบัตร'!A:F`
   - อ่านระดับเหรียญจากคอลัมน์ E โดยตรง
   - รองรับลิงก์เกียรติบัตร PDF, Google Drive และสูตร `=HYPERLINK(...)` ในคอลัมน์ F
   - มีระบบเปิดดูเกียรติบัตร (PDF Preview Modal) และปุ่มดาวน์โหลดไฟล์
5. **ระบบจัดการแอดมิน (Admin CMS):**
   - ล็อกอินด้วยชื่อผู้ใช้และระบบตรวจสอบความปลอดภัย
   - ปรับแต่งข้อความ, รูปภาพ, สไลด์, เกณฑ์รางวัล, กำหนดการ, ประกาศ, ข้อสอบ และ Footer
   - บันทึกการแก้ไขลงใน Google Sheets คอลัมน์ H:O เพื่อให้อัปเดตตรงกันทุกอุปกรณ์โดยไม่ต้อง Deploy ใหม่
6. **คู่มือฉบับสมบูรณ์ในโฟลเดอร์ `/docs/`:**
   - `docs/SETUP.md`
   - `docs/DATABASE.md`
   - `docs/BACKEND.md`
   - `docs/GITHUB_PAGES.md`
