## 1. แผ่นงาน: ตรวจสอบคะแนน
- **ชื่อชีต:** `ตรวจสอบคะแนน`
- **ช่วงข้อมูลที่อ่าน:** `'ตรวจสอบคะแนน'!A:F`
- แถวที่ 1 คือ หัวตาราง
- ข้อมูลเริ่มต้นแถวที่ 2

| คอลัมน์ | ชื่อข้อมูล | การนำไปใช้ |
|---|---|---|
| A | เลขที่ | แสดงลำดับ/เลขที่ของผู้เข้าสอบ |
| B | ชื่อ-นามสกุล | ใช้ค้นหา (รองรับการตัดคำนำหน้า เช่น ด.ช., ด.ญ., นาย, นางสาว) |
| C | ระดับชั้น | แสดงระดับชั้น (ม.1 - ม.6) และใช้กรองกรณีชื่อซ้ำ |
| D | ห้อง | แสดงห้องเรียน (เช่น ห้อง 1, 8) |
| E | คะแนนที่ได้ | **อ่านค่าคะแนนจริงจากคอลัมน์นี้โดยตรง** |
| F | ผลการประเมิน | **อ่านค่า "ผ่าน" หรือ "ไม่ผ่าน" จากคอลัมน์นี้โดยตรง (ห้ามคำนวณแปลงค่าเอง)** |

## 2. แผ่นงาน: ดาวน์โหลดเกียรติบัตร
- **ชื่อชีต:** `ดาวน์โหลดเกียรติบัตร`
- **ช่วงข้อมูลที่อ่าน:** `'ดาวน์โหลดเกียรติบัตร'!A:F`
- แถวที่ 1 คือ หัวตาราง
- ข้อมูลเริ่มต้นแถวที่ 2

| คอลัมน์ | ชื่อข้อมูล | การนำไปใช้ |
|---|---|---|
| A | เลขที่ | แสดงลำดับ/เลขที่ |
| B | ชื่อ-นามสกุล | ใช้ค้นหาชื่อผู้ได้รับเกียรติบัตร |
| C | ระดับชั้น | แสดงระดับชั้น |
| D | ห้อง | แสดงห้องเรียน |
| E | ระดับเหรียญ | **อ่านระดับเหรียญ (เหรียญทอง, เหรียญเงิน, เหรียญทองแดง, ชมเชย) จากคอลัมน์นี้โดยตรง** |
| F | ดาวน์โหลดเกียรติบัตร | ลิงก์ไฟล์ PDF (รองรับทั้ง Direct Link, Google Drive, และสูตร `=HYPERLINK(...)`) |

## 3. พื้นที่จัดเก็บ CMS (Columns H:O)
สำหรับจัดเก็บข้อมูลการแก้ไขหน้าเว็บไซต์จากระบบแอดมิน เพื่อให้แสดงผลตรงกันทุกอุปกรณ์โดยไม่ต้องสร้างแผ่นงานใหม่:
- **แผ่นงาน:** `ตรวจสอบคะแนน`
- **ช่วงคอลัมน์:** `H:O` (แถวที่ 2 เป็นต้นไป)
  - H: `CMS_ID`
  - I: `CMS_SECTION`
  - J: `CMS_TYPE`
  - K: `CMS_KEY`
  - L: `CMS_VALUE_JSON`
  - M: `SORT_ORDER`
  - N: `IS_ACTIVE`
  - O: `UPDATED_AT`
- ระบบตรวจสอบก่อนบันทึกเสมอว่าพื้นที่ดังกล่าวปลอดภัย และไม่มีการแตะต้องคอลัมน์ A:F
